# 📐 線性規劃｜互動學習網

高中「選修數學乙（下）第 1 章 線性規劃」互動學習網站。純 HTML／CSS／JavaScript，無外部套件、可離線使用，適合直接部署到 GitHub Pages。

## 功能
- **學習指引**：學習目標、學習路徑、建議時程、先備知識檢核、解題四步驟
- **教材**：忠實呈現課本內容（章首、平行直線系、二元一次不等式、線性規劃、歷史），例題可展開解答，隨堂練習可自我檢核
- **互動實驗室**：A 平行直線系／B 半平面與測試點／C 可行解區域掃描器（含自訂限制條件、頂點法表格）／D 旋轉目標函數（多重最佳解）／E 格子點計數
- **習題**：基本題、進階題、素養題，含提示、詳解、圖形與自我標記
- **練習**：直線平移、半平面判斷、求頂點、求最大／最小值，隨機出題無限練習
- **測驗**：25 題題庫隨機抽 10 題，計分與逐題檢討
- **延伸學習**：無界區域、多重最佳解、無可行解、整數規劃、單形法、常見迷思
- **學習歷程**：自動紀錄，可下載 HTML 報告、CSV、JSON；可下載原始教材 PDF
- **⚙️ 顯示與操作設定**：全螢幕、音效、裝置、版面、語言（繁中／英文）、字體、色系

## 檔案結構
```
linear-programming/
├── index.html                  # 首頁
├── css/style.css               # 樣式（亮色／暗色、響應式）
├── js/data.js                  # 英文介面字典、測驗題庫、預設題目
├── js/plot.js                  # SVG 坐標平面繪圖引擎＋課本圖形
├── js/app.js                   # 主程式（路由、實驗室、練習、測驗、歷程、設定）
├── assets/linear-programming-textbook.pdf   # 原始教材
├── .nojekyll
└── README.md
```

## 部署到 GitHub Pages
1. 在 GitHub 建立新的 repository，將本資料夾所有檔案上傳（保持資料夾結構）。
2. 進入 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`／`/(root)`，儲存。
3. 約 1 分鐘後即可由 `https://<帳號>.github.io/<repository>/` 開啟。

> 學習紀錄僅儲存在學生瀏覽器的 localStorage，不會上傳任何個人資料。
